# 공학용 힘 단위 변환기

## 프로그램 용도

Tkinter 그래픽 화면에서 힘의 크기를 입력하고 `kN`, `N`, `kgf` 단위로 변환하는 프로그램입니다. 변환 결과는 `N`과 `kgf`로 표시되며, 변환한 값은 화면의 변환 기록에 추가됩니다.

## 필요 환경

- Python 3
- Tkinter가 설치된 Python 환경
- 그래픽 화면을 표시할 수 있는 데스크톱 환경

별도 외부 Python 패키지는 사용하지 않습니다. Windows용 일반 Python 설치에는 Tkinter가 포함되어 있지만, 설치 구성에 따라 다를 수 있습니다.

## 실행

PowerShell에서 이 폴더로 이동한 뒤 실행합니다.

```powershell
python ".\python force_converter_gui 2.py"
```

## 입력 방법

1. 숫자 입력란에 힘의 크기를 입력하거나 화면의 숫자 버튼을 누릅니다.
2. 입력 단위에서 `kN`, `N`, `kgf` 중 하나를 선택합니다. 기본 단위는 `kN`입니다.
3. `변환`을 누릅니다. 결과는 `N`과 `kgf`로 표시됩니다.

소수점 입력이 가능하며, 입력값은 유한한 0 이상의 숫자여야 합니다.

## 입력 예시

| 입력값 | 입력 단위 | 표시 결과 |
| ---: |:---:|:---|
| `2.5` | `kN` | `2,500.00 N`, `254.93 kgf` |
| `500` | `N` | `500.00 N`, `50.99 kgf` |
| `10` | `kgf` | `98.07 N`, `10.00 kgf` |
| `0` | `N` | `0.00 N`, `0.00 kgf` |

## 오류 입력 예시

아래 입력은 변환할 수 없으며 결과 영역에 `잘못된 입력`이 표시됩니다.

| 입력값 | 단위 | 이유 |
|:---|:---:|:---|
| 비워 둠 | `kN` | 숫자가 입력되지 않음 |
| `abc` | `N` | 숫자로 변환할 수 없음 |
| `-3` | `kgf` | 음수 입력은 허용되지 않음 |
| `NaN` 또는 `inf` | `N` | 유한한 숫자가 아님 |
| `5` | `lb` | 지원하지 않는 단위 |
